Guía DOM: HTML y JavaScript
Guía de aprendizaje · JavaScript

Introducción a DOM

En esta guía vas a construir un proyecto en tres partes: un saludo que usa el DOM de cuatro formas distintas, un registro con dos campos y variables, y una conversión de números con parseInt, parseFloat y Number. Cada parte explica, en el momento en que la necesitas, el concepto de JavaScript que la hace funcionar.

Ruta de aprendizaje

Proyecto DOM · Paso 1

Enlazar el HTML con el CSS y el JavaScript

1Los tres archivos

Una página web se construye con tres lenguajes, y cada uno tiene un trabajo distinto. Si los mezclas en un solo archivo, el código se vuelve difícil de leer y de corregir. Por eso cada lenguaje va en su propio archivo.

ArchivoLenguajeSu trabajo
index.htmlHTMLQué hay en la página: títulos, campos, botones.
css/style.cssCSSCómo se ve: colores, tamaños, espacios.
js/script.jsJavaScriptQué hace: lo que pasa al hacer clic.

2La estructura de carpetas

Explorador de VS Code
  • DOM2carpeta principal del proyecto
  • csscarpeta para los estilos
  • style.cssel diseño
  • jscarpeta para JavaScript
  • script.jsel comportamiento
  • index.htmlla estructura (va en la raíz)
Reglas para nombrar
  • Sin espacios ni tildes: script.js sí; mi script.js no.
  • Mayúsculas y minúsculas importan: para el navegador css y CSS son carpetas distintas.
  • Revisa la extensión: si el archivo quedó como style.css.txt, no funcionará.

3Enlazar con <link> y <script>

Crear los tres archivos no es suficiente: el index.html todavía no sabe que existen. Hay que enlazarlos, es decir, escribir en el HTML dónde están.

Para el CSS: <link>

Va dentro del <head>. El atributo href dice dónde está el archivo de estilos.

Para el JS: <script>

Va al final del <body>. El atributo src dice dónde está el archivo de JavaScript.

index.html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Proyecto DOM</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <main>
        <!-- aquí van las secciones del proyecto -->
    </main>

    <script src="js/script.js"></script>
</body>
</html>
  1. lang="es": le dice al navegador que la página está en español.
  2. href="css/style.css": se lee como "entra a la carpeta css y abre style.css".
  3. src="js/script.js": "entra a la carpeta js y abre script.js". Va justo antes de </body>.

4¿Por qué el script va al final?

El navegador lee el HTML de arriba hacia abajo, línea por línea, y va construyendo la página a medida que avanza. Si el script estuviera en el <head>, JavaScript intentaría buscar un campo de texto que el navegador todavía no ha leído, y no lo encontraría.

Script arriba

JavaScript se ejecuta antes de que existan los inputs. Al buscarlos, recibe null y aparece un error.

Script al final

Cuando JavaScript se ejecuta, el navegador ya leyó todo el HTML. Todos los elementos existen.

Proyecto DOM · Paso 2

Proyecto · Parte 1: saludo con el DOM

1¿Qué es el DOM?

Tu archivo index.html es solo texto. Cuando el navegador lo abre, lo convierte en una representación en forma de árbol que JavaScript sí puede leer y modificar. Esa representación se llama DOM (Document Object Model): cada etiqueta se vuelve un objeto con propiedades que se pueden leer y cambiar.

Idea clave

En JavaScript, la palabra document representa la raíz del árbol, es decir, toda la página. Todo lo que hagas con el DOM empieza escribiendo document.

2Encontrar el campo: id y getElementById

Una página puede tener varios campos de texto. Para que JavaScript sepa cuál leer, cada campo necesita un nombre único: el atributo id, que no se puede repetir en la misma página.

js/script.js
document.getElementById("nombre")
  1. document: entra a la página (la raíz del árbol).
  2. .getElementById: "obtener elemento por id". Es la instrucción que busca.
  3. ("nombre"): el id que quieres encontrar, entre comillas. Debe ser idéntico al del HTML.
Atención a las mayúsculas

Se escribe getElementById: la E, la B y la I van en mayúscula. Y el id del HTML debe coincidir exactamente: nombre no es lo mismo que Nombre.

3Mostrar el resultado de cuatro formas

Una vez encontrado el campo, puedes leer su valor o escribir en otro elemento. Este ejercicio muestra el mismo saludo de cuatro maneras distintas, para comparar cada una:

InstrucciónQué hace
alert(...)Muestra el mensaje en una ventana emergente.
.value = ...Escribe el texto dentro de un input (reemplaza lo que haya).
.innerText = ...Inserta texto visible dentro de una etiqueta.
.innerHTML = ...Inserta texto e interpreta las etiquetas HTML que traiga.
.textContent = ...Inserta texto sin interpretar etiquetas HTML.
document.write()

Escribe directo en el documento, pero si se ejecuta después de que la página ya cargó, puede reemplazar toda la página. Por eso casi nunca se usa fuera de ejemplos como este.

        <br>
        <input type="text" id="resultado">

        <div id="resultado2">Aqui se mostrara el resultado 2</div>

        <div id="resultado3">Aqui se mostrara el resultado 3</div>

        <div id="resultado4">Aqui se mostrara el resultado 4</div>

js/script.js
function saludar() {

    // .value permite leer el valor de un campo de formulario
    let nombre = document.getElementById("nombre").value;

    // 1. Mostrar información en una ventana emergente
    alert(`Hola ${nombre}`);

    // 2. Mostrar información dentro de un input
    document.getElementById("resultado").value = `Hola, ${nombre}`;

    // 3. .innerText inserta texto visible dentro de una etiqueta
    document.getElementById("resultado2").innerText = `Hola, ${nombre}`;

    // 4. .innerHTML interpreta las etiquetas HTML del texto
    document.getElementById("resultado3").innerHTML =
        `<p style="color: red;">Hola, ${nombre}</p>`;

    // 5. .textContent inserta texto sin interpretar etiquetas
    document.getElementById("resultado4").textContent = `Hola, ${nombre}`;

    // 6. document.write() escribe directo en el documento (ver advertencia arriba)
    document.write(`Hola, ${nombre}`);

}

Proyecto DOM · Paso 3

Proyecto · Parte 2: registro con variables y eventos

1Variables: let y const

Cuando JavaScript lee un dato, necesita guardarlo en algún lugar para usarlo después. Ese lugar es una variable.

const · constante

Guarda un valor que no se va a reemplazar.

let · variable

Guarda un valor que sí puede cambiar más adelante.

Sobre este ejercicio

registrar() usa let para nombre y programa, aunque en este caso podría usar const: ninguno de los dos vuelve a cambiar dentro de la función. Regla práctica: empieza siempre con const y cámbiala a let solo si vas a reasignar la variable.

2Una función, dos campos

Una función es un grupo de instrucciones con un nombre. Declararla (escribirla en script.js) no la ejecuta; para que corra hay que llamarla por su nombre con paréntesis. registrar() lee dos campos en vez de uno, y usa el mismo valor leído varias veces dentro de la misma plantilla de texto.

  • Nombra la función con un verbo en camelCase: registrar, no Registrar ni registro.
  • Las variables creadas dentro de una función solo existen dentro de ella.

3onclick y por qué type="button"

onclick conecta un evento con tu código: "cuando el usuario haga clic, ejecuta esta función". El nombre debe ser exactamente igual al de la función en script.js.

CódigoAl hacer clic dentro de un form
<button type="submit">Envía el formulario y recarga la página (se pierde el resultado).
<button type="button">Solo ejecuta su onclick.
Regla

Si un botón está dentro de un <form> y su trabajo es ejecutar una función de JavaScript, escríbelo siempre con type="button".

Ids distintos a la Parte 1

Si esta sección vive en la misma página que la Parte 1, sus campos no pueden llamarse nombre otra vez: el id debe ser único en toda la página. Por eso aquí se usan nombre2 y programa2.

js/script.js
function registrar() {

    // Obtener los datos ingresados por el usuario
    let nombre = document.getElementById("nombre2").value;
    let programa = document.getElementById("programa2").value;

    // 1. Mostrar los datos en una ventana emergente
    alert(`Aprendiz: ${nombre}\nPrograma: ${programa}`);

    // 2. Mostrar la información en un input
    document.getElementById("resultado11").value =
        `${nombre} - ${programa}`;

    // 3. Mostrar texto utilizando innerText
    document.getElementById("resultado22").innerText =
        `Nombre: ${nombre} | Programa: ${programa}`;

    // 4. Mostrar contenido HTML con formato
    document.getElementById("resultado33").innerHTML =
        `<p style="color: blue;">
            <strong>Aprendiz:</strong> ${nombre}<br>
            <strong>Programa:</strong> ${programa}
        </p>`;

    // 5. Mostrar texto utilizando textContent
    document.getElementById("resultado44").textContent =
        `El aprendiz ${nombre} está inscrito en ${programa}.`;

    // 6. Mostrar los datos en la consola del navegador
    console.log("Nombre:", nombre);
    console.log("Programa:", programa);

}

Proyecto DOM · Paso 4

Proyecto · Parte 3: convertir texto en números

1Todo lo que viene de un input es texto

JavaScript trabaja con distintos tipos de datos. Los dos que más usamos son string (texto, entre comillas) y number (número, sin comillas). Aquí está el detalle que causa más errores: la propiedad .value siempre devuelve texto, incluso si el input es type="number".

Y el signo + se comporta distinto según el tipo:

Con textos: pega
"5" + "3"   // "53"
Con números: suma
5 + 3       // 8
Conclusión

Antes de hacer cualquier operación matemática con un dato del formulario, conviértelo en número con parseInt, parseFloat o Number.

2parseInt, parseFloat y Number: compáralos

Los tres convierten texto en número, pero cada uno se comporta distinto frente al mismo dato:

EntradaparseIntparseFloatNumber
"25"252525
"7.9"77.97.9
"12abc"1212NaN
"" (vacío)NaNNaN0
  • parseInt toma los dígitos de izquierda a derecha y corta en el primer carácter que no sea número; descarta los decimales.
  • parseFloat hace lo mismo pero conserva los decimales.
  • Number revisa el texto completo: si una sola parte no es válida, devuelve NaN; y un campo vacío se vuelve 0, no NaN.
¿Qué es NaN?

Significa Not a Number, "no es un número". Cualquier operación con NaN también da NaN.

3El ejercicio completo

index.html
<section>
    <form action="">
        <h3>Tercer Ejercicio DOM: operaciones numéricas</h3>

        <label for="valorUno">Valor 1: </label>
        <input type="text" id="valorUno" placeholder="Ej: 15.8">

        <label for="valorDos">Valor 2: </label>
        <input type="text" id="valorDos" placeholder="Ej: 4.25">
        <br>

        <button type="button" onclick="calcularOperaciones()">Calcular</button>
        <button type="reset">Cancelar</button>
    </form>

    <h2>Resultados</h2>

    <p>Con parseInt(): <span id="resParseInt"></span></p>
    <p>Con parseFloat(): <span id="resParseFloat"></span></p>
    <p>Con Number(): <span id="resNumber"></span></p>
    <p>Suma usando parseFloat(): <span id="resSuma"></span></p>
</section>
js/script.js
function calcularOperaciones() {

    // Los dos campos llegan siempre como texto, sin importar lo que el usuario escriba
    let valor1 = document.getElementById("valorUno").value;
    let valor2 = document.getElementById("valorDos").value;

    // 1. parseInt(): toma los dígitos y corta en el primer decimal
    let entero1 = parseInt(valor1);
    let entero2 = parseInt(valor2);
    document.getElementById("resParseInt").textContent =
        `parseInt("${valor1}") = ${entero1} | parseInt("${valor2}") = ${entero2}`;

    // 2. parseFloat(): igual que parseInt, pero conserva los decimales
    let decimal1 = parseFloat(valor1);
    let decimal2 = parseFloat(valor2);
    document.getElementById("resParseFloat").textContent =
        `parseFloat("${valor1}") = ${decimal1} | parseFloat("${valor2}") = ${decimal2}`;

    // 3. Number(): revisa el texto completo; si no es válido, da NaN
    let numero1 = Number(valor1);
    let numero2 = Number(valor2);
    document.getElementById("resNumber").textContent =
        `Number("${valor1}") = ${numero1} | Number("${valor2}") = ${numero2}`;

    // 4. Suma usando los valores convertidos con parseFloat, para no perder decimales
    let suma = decimal1 + decimal2;
    document.getElementById("resSuma").textContent =
        `${decimal1} + ${decimal2} = ${suma}`;

}

Prueba tu proyecto
  • Escribe 15.8 y 4.25: compara cómo cambia cada resultado.
  • Deja un campo vacío: parseInt y parseFloat dan NaN, pero Number da 0.
  • Escribe letras en un campo: solo Number rechaza el texto completo.
Errores comunes en estos tres ejercicios
  • Cannot read properties of null: el id del HTML y el de getElementById no coinciden (revisa mayúsculas).
  • saludar is not defined (o registrar/calcularOperaciones): el nombre del onclick no es idéntico al de la función, o falta enlazar script.js.
  • Assignment to constant variable: intentaste cambiar el valor de una const; usa let.
  • Resultado como "53" en vez de 8: falta convertir el texto con parseInt, parseFloat o Number antes de sumar.
